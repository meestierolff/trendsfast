## Short description

One evidence-backed distribution move for technical founders: what to say,

signal is not good enough.

## Long description

TrendsFast is an open-source distribution intelligence API for technical solo
founders and small AI, B2B SaaS, and developer-tool teams. A scan turns a product
URL and bounded current evidence into one `PUBLISH`, `REPLY`, `REMIX`, or `WAIT`
decision. It never auto-posts and does not promise virality.

Self-hosters use the real AGPL decision engine with their own provider keys. The
managed-cloud hypothesis adds provider accounts, history, scheduling, retries,
cost control, and support.
