1. I can build products faster than I can distribute them.

   The bottleneck became the same research loop every week: conversations,
   search demand, developer activity, videos, launches, news—then still deciding
   what was worth saying.

2. More data did not solve it. A feed of 100 “trending” posts just moved the
   work.

   General LLM ideas were fast, but without current receipts they often sounded
   like ideas anyone in the category could publish.

3. So I built TrendsFast around one answer:

   **Your next distribution move**

   `PUBLISH` · `REPLY` · `REMIX` · `WAIT`

4. A move includes the channel, angle, hook, outline, why now, original evidence
   URLs, confidence, limitations, and a validity window.

   `WAIT` is a feature. Weak or dependent evidence should stop content, not
   manufacture urgency.

5. The model cannot create evidence. Signals are stored first, filtered and
   ranked deterministically, then a constrained model can propose language. URLs
   and metrics are rebound from stored records before founder review.
