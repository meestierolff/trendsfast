# Free-scan reply templates

Use manually, personalize, and follow each community's rules. Never collect a
private/admin URL, secret, or sensitive data. Move product details to a private
channel when the thread should not contain them.

## Public invitation reply

Happy to run one. Please share only the public product URL. The current free form
accepts that URL and infers context from public content; it does not collect
private context or channel preferences. I’ll return one founder-reviewed
`PUBLISH`, `REPLY`, `REMIX`, or `WAIT` with original evidence links and
limitations. Nothing becomes a public case study without your explicit
permission.

## Acknowledgement after submission

Got it: `[PUBLIC URL]`. I’ll treat the site/provider text as untrusted evidence,
review the inferred context and result myself, and send a private link. Current
coverage/limitations for this run: `[ACTUAL STATUS]`. There’s no auto-posting or
card.

## Missing context

The current public form has no context-edit journey. If the public site does not
support a trustworthy inference, return `WAIT` or decline the scan; do not ask
for private material and then imply the product used it. Never request login
credentials, internal links, customer data, or unpublished material.

## Delivery

Here’s the private result: `[PRIVATE LINK — NEVER POST IN A PUBLIC REPLY]`.
It recommends `[ACTION]` and includes the receipts, assumptions, limitations,
and validity window. Could you choose one: “I would use this,” “relevant, wrong
angle,” “not relevant,” “I used/published this,” or “request another scan”?

## Honest `WAIT`

The reviewed result is `WAIT`: `[PLAIN REASON]`. The available evidence did not
clear the quality floor because `[COVERAGE / RELEVANCE / INDEPENDENCE / TIMING]`.
I’d rather return that than invent urgency. If `[SPECIFIC MISSING INPUT/SOURCE]`
changes, a new scan may be useful.

## Decline / capacity

Thanks for asking. I’ve reached the number of scans I can review responsibly
this round, so I can’t promise a useful delivery time. I can add you to
`[CONSENTED FOLLOW-UP METHOD]` or you can run the fixture demo at `[REPO LINK]`.

## Public case-study permission (separate, optional)

Would you be open to a public case study that names `[PRODUCT]` and shows the
specific result/evidence/correction/outcome? “No” has no effect on your scan.
If yes, I’ll send the exact draft and assets for approval before publishing, and
you can request removal later. Please answer explicitly; silence is not consent.
