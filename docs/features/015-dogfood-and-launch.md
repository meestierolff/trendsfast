# 015 — Dogfood and evidence-led launch

Status: launch procedure; no dogfood or public outcome is claimed yet.

## User problem

The product must demonstrate differentiated recommendations and honest proof
before an unknown founder trusts it.

## Scope

Eight authorized product scans, cross-result quality review, provider
actual/unknown cost plus separately labeled conservative model reservations,
review-time measurement, nine launch assets, explicit public consent, tracked
URLs, and weekly open metrics.

## Non-goals

Manufactured testimonials/traction, bulk outreach, spam, guaranteed outcomes,
or public case studies without permission.

## Product contract

Each dogfood output materially differs in audience, query plan, source weights,
topic, action, channel, format, evidence, and limitations for product-grounded
reasons. Repeated generic advice blocks launch.

## API contract

Use the same scan/review/delivery/feedback endpoints as external users. Public
case-study flag is explicit, revocable consent, not an operator shortcut.

## Data model

Store consent, attribution, review correction/time, provider ledger, feedback,
used outcome, case-study version, and takedown/revocation audit.

## Provider/legal constraints

Founder confirms each URL/owner and every live provider gate. Launch posts follow
community rules; Reddit distribution is manual and separate from automation.

## Security considerations

No private tokens/data in screenshots, posts, analytics, or case studies;
permission and removal path are recorded.

## Tests written first

- Fixture golden set varies on all required dimensions.
- Generic-output similarity threshold flags review.
- Public transition requires explicit consent.
- Metrics exclude fixtures/unknown cost and disclose denominators.
- Tracked links contain no private data.

## Implementation

Follow `DOGFOOD_RUNBOOK.md`; edit repository templates with observed facts only
after results exist.

## Verification

Founder reviews all eight side-by-side, validates every URL at delivery, and
signs the launch checklist with provider actual/unknown cost, unsettled model
usage, dated price metadata, and review evidence. A conservative reservation is
not actual model cost.

## Limitations

Eight founder-linked products are a learning set, not broad market validation.

## Rollout

Offer a small number of free founder-reviewed scans and publish only
permissioned, denominator-backed learning.

Canonical founder message:

> I was spending hours searching social media and search demand for something
> relevant to distribute. TrendsFast now gives my agents one evidence-backed
> Next Move from a product URL.

Canonical CTA:

> Drop your product URL. I’ll run a free founder-reviewed trend and distribution
> scan.

## Rollback

Pause intake, retract inaccurate public material, honor takedowns, and keep
private audit facts needed to correct the system.
